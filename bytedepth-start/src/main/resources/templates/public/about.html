这里是 bytedepth — 字节深处

网站简介

bytedepth（字节深处）是一个专注于 技术深度的个人博客。 名字取自"字节"与"深度"——在这里，我希望每一篇文章都能超过表面， 真正钻进某个技术问题的内部，把原理、细节和取舍说清楚。

这里不追热点，不堆砌概念。写一篇文章，至少要把一个点讲透： 为什么这样设计？代价是什么？有没有更好的做法？

内容方向

文章以 Java 后端 / 系统设计 为主线，兼顾工程实践与性能调优。 具体来说会写：

技术原理 — JVM、并发、数据库内核、分布式协议，追根溯源而不只是 API 用法。

工程实践 — 代码设计、架构演进、踩坑记录，真实项目里的权衡与教训。

专栏系列 — 将同一主题的文章串成系列，系统性地把一个领域从入门讲到深水区。

站点技术栈

这个博客本身也是一个练手项目，采用 DDD 分层架构，自己从零搭建：

Java 21 Spring Boot 3 MyBatis-Plus MySQL Thymeleaf Docker Nginx

源码在 GitHub 上开放，欢迎参考或提 Issue。
