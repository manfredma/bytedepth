这里是 bytedepth — 字节深处

网站简介

bytedepth（字节深处）是我的个人技术博客， 专注于把一个知识点钻到深处。 名字取自"字节"与"深度"——希望每一篇文章都能越过表面的用法， 真正走进某个技术问题的内部，把原理、细节和取舍讲清楚。

这里不追热点，不堆砌概念，也很少转载二手信息。写一篇文章，至少要把一个点讲透： 为什么这样设计？代价是什么？有没有更好的做法？以及——它在我自己的项目里是怎么落地的。

内容方向

围绕 后端开发与计算机基础 展开，按分类沉淀，按专栏串读。 目前站内的几个主要分类：

架构设计 — 分层、DDD、服务化、演进式架构，把"为什么这么分层"讲到底。

计算机基础 — 操作系统、网络、数据结构等底层原理，撑起上层一切框架。

开发框架 — Spring、MyBatis-Plus 等主流框架的原理剖析与实战要点，不止于会用。

数据库 — MySQL 索引、事务、锁、执行计划，从 SQL 调优到存储引擎内核。

AI Coding — AI 辅助编程的实践、工具链与思考，记录这个新范式下的工作方式。

此外，专栏 会把同一主题的文章串成系列，从入门讲到深水区； 项目 页则陈列我的 side project，记录想法、技术栈与上线情况。

站点功能

除了阅读文章，你还可以在这里：

专栏阅读 — 按系列浏览文章，跟着顺序从基础读到进阶，避免在零散篇幅里迷路。

全文搜索 — 顶部搜索框直达关键词，快速定位到想看的内容。

主题切换 — 内置默认、纸张阅读、清爽蓝、森林绿、深夜代码、玫瑰暖色等多套主题，随喜好切换。

账号与互动 — 注册登录后进入个人主页，参与评论与互动；作者可在后台发布与管理文章。

PWA 支持 — 可将站点添加到主屏幕，像原生应用一样阅读。

站点技术栈
