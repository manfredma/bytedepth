# 前端组件约束

组件入口和现有分页、确认弹窗的接入方式见 [前端公共组件模式](../engineering/frontend-patterns.md)。

- 组件必须自隔离：组件内部的字体、字号、间距、颜色、reset 等外观规则由组件自己的 class/CSS 控制，不依赖页面级 `body`、`*`、`:root` 或其他组件样式。
- 组件样式选择器必须收敛在组件命名空间内（如 `.nav-*`、`.xxx-*`），避免影响页面或其他组件。
- 组件之间只允许通过布局容器产生相对位置关系；除相对位置外，不允许组件之间通过继承、全局选择器或共享裸 class 互相影响。
- 新增或改造公共组件时，优先抽离独立 CSS 文件，并显式声明组件基准字体、字号、盒模型和必要变量默认值。
