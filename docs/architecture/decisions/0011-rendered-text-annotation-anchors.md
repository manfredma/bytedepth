# ADR-0011: 批注使用阅读页渲染文本作为锚点

- **状态**: Accepted
- **日期**: 2026-09-21
- **决策者**: 项目所有者

## 上下文

批注的 `start_offset`、`end_offset` 是浏览器正文容器中实际文本节点的字符偏移，但文章正文持久化为 Markdown。若文章更新后直接对 Markdown 源文做 diff，标题标记、强调标记、代码围栏和段落结构等不可见语法会改变偏移，导致批注划线和评注定位错误。

批注还需要处理锚定文字被部分删除、完全删除或替换的情况。无法确认旧偏移仍对应创建批注时的选中文字时，继续迁移会把批注静默放到错误文字上。

## 决策

批注重算统一基于与阅读页 HTML `textContent` 对齐的 Markdown 渲染文本投影做字符级 diff；文章更新后对仍能确认的批注迁移偏移并同步 `selected_text`。若锚定范围被完全删除、替换，或旧偏移无法还原原 `selected_text`，将批注标记为逻辑删除，使其不再显示。

不直接对 Markdown 源文做 diff，因为源文包含阅读页不可见语法；不依赖全文搜索 `selected_text` 重新定位，因为重复文字无法唯一确定原锚点，也不能可靠区分被修改的文字。

## 后果

**正向**

- Markdown 结构和格式变化不会再把批注偏移推离阅读页文字。
- 删除或替换锚定文字时不会把旧评注错误显示在邻近文字上。
- 仍存活的批注会同步新的 `selected_text`，前端划线与侧栏引用保持一致。

**负向**

- Markdown 渲染规则变化需要同步更新文本投影和相关测试。
- 无法可靠确认锚点时选择隐藏批注，可能需要用户重新划线，而不是冒险自动恢复。
- 字符级 diff 的计算成本随正文长度增加；当前文章规模下优先保证锚点正确性。

## 假设

| 假设 | 可证伪信号（出现时重评） |
|------|--------------------------|
| 阅读页正文继续由服务端 Markdown 渲染为 HTML，并以正文容器的文本节点作为批注坐标空间 | 前端改为虚拟化、异步拼接或客户端重新渲染正文，导致服务端投影与浏览器 `textContent` 不一致 |
| `selected_text` 可用于验证旧偏移，而不是唯一重定位键 | 批注协议改为提供稳定 AST 节点 ID、字符锚点或版本化编辑操作 |

## 退出条件

| 信号 | 预设行动 |
|------|----------|
| 需要跨大规模重排、重复文字精确恢复或协同编辑 | 引入版本化文本锚点或结构化编辑操作，并评估是否保留本 ADR 的逻辑隐藏兜底 |
| 服务端与浏览器的 Markdown 渲染结果出现可观测差异 | 提取共享渲染/文本投影组件，或在 staging E2E 中增加渲染文本一致性校验 |
