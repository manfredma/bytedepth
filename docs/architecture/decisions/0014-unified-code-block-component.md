# ADR-0014: 所有顶层代码块统一使用可展开代码组件

- **状态**: Accepted
- **日期**: 2026-09-23
- **决策者**: 项目所有者
- **取代**: [ADR-0013](0013-opt-in-code-block-enhancements.md)

## 上下文

文章正文中的代码块需要统一的可读性和操作体验：语言标记、语法高亮、行号、复制以及展开/收起应保持一致。现有文章同时存在有语言标记和未标注语言的 fenced code block，未标注语言的代码也必须继续完整展示，不能因为增强处理而丢失正文、缩进或复制内容。

原 ADR-0013 只对显式 `title`、`fold` 或 `tabs` 元数据启用增强组件，因此普通代码块不会有工具栏；这与项目所有者验收后的目标不一致。新的决策保留 Markdown 正文兼容性，但统一代码块的展示外壳。

## 决策

bytedepth 对文章正文中所有顶层 fenced code block 使用统一代码块组件。组件的共同能力包括：

- 左侧显示语言；没有语言时显示中性的 `Code`，不猜测语言；
- 可选显示 `title:` 或 `file:` 提供的标题；没有元数据时绝不生成文件名；
- 每个代码块始终显示复制按钮和展开/收起按钮；
- 代码块默认展开；只有显式 `fold` 元数据才默认收起；`fold` 只控制初始状态，不控制按钮是否存在；
- 有语言标记时由语法高亮层处理；没有语言或不支持语言时回退为纯文本，原始代码正文保持不变；
- 连续且显式声明相同 `tabs:<group>` 的代码块组成多语言 Tab。Tab 面板使用两行结构：第一行切换语言，第二行显示当前面板的语言、展开/收起和复制操作；每个面板独立保留行号和展开/收起状态；
- 收起状态使用弱强调标题栏和醒目的“展开”按钮；展开状态使用普通标题栏和中性“收起”按钮；颜色不是唯一状态信号，按钮文本与 `aria-expanded` 必须同步表达状态；
- 代码块的标题、语言和操作区使用统一布局。复制按钮始终位于操作区最右侧，折叠按钮位于其左侧。

增强范围继续限定为顶层 fenced code block；引用块、列表项中的嵌套代码和其他 CommonMark 节点仍由 CommonMark 原生渲染，后续如需递归增强必须单独设计节点边界和 Tab 分组规则。

Markdown 示例：

````markdown
```java
Product product = Product.builder().build();
```

```java fold title:"长代码示例"
// 默认收起，但仍可展开
```

```java tabs:install
// Java
```

```python tabs:install
# Python
```
````

没有 `title:` 或 `file:` 的代码块不会显示文件名；文件名不是从语言、类名或代码正文推断的。

## 方案取舍

采用服务端生成稳定的组件语义结构，前端 JavaScript 只负责复制、展开/收起和 Tab 状态，不依赖 Obsidian 插件生成的 DOM。语法高亮可以由 PrismJS 等成熟高亮层提供，但高亮失败不能阻止代码正文渲染。

放弃以下方案：

- 继续让普通代码块走旧 `<pre><code>` 路径：无法满足所有代码块统一操作体验；
- 只在 `fold` 元数据存在时渲染展开按钮：会让不同代码块的工具栏不一致；
- 根据相邻语言自动合并 Tab：无法区分作者想展示多个独立代码块还是多语言实现；
- 自动猜测未标注语言或自动生成文件名：容易产生错误语言和虚构上下文；
- 将语法高亮失败作为渲染失败：会破坏已有文章内容。

## 后果

**正向**

- 新旧代码块拥有一致的复制、展开/收起和视觉结构；
- 未标注语言、未知语言和特殊字符仍可安全回退为纯文本；
- `fold` 的语义简单明确，只表示默认折叠；
- 文件名是可选元数据，不会污染默认笔记的展示；
- 多语言 Tab 的每个面板拥有独立的行号、代码正文和展开/收起控制。

**负向**

- 存量代码块的 DOM 和视觉结构会统一升级，需要完整回归普通代码、Mermaid、移动端和主题；
- 代码块组件需要维护服务端 HTML、主题 CSS、交互 JavaScript 及对应测试；
- 高亮库的语言覆盖和体积需要在正式实现时单独评估，不能阻塞纯文本回退。

## 验收信号

| 信号 | 要求 |
|------|------|
| 普通有语言代码块 | 显示语言、行号、复制和展开/收起，默认展开 |
| 未标注语言代码块 | 显示 `Code`、行号、复制和展开/收起，不猜测语言、不生成文件名 |
| 显式 `fold` | 初始收起，标题栏弱强调，展开按钮强强调 |
| 显式标题 | 仅显示作者提供的 `title:`/`file:` 值 |
| 多语言 Tab | 两行结构；各语言面板均有行号、复制和展开/收起 |
| 代码渲染失败 | 高亮失败时仍输出原始代码正文，不能出现空代码块 |

## 退出条件

如果统一组件对存量文章造成不可接受的 DOM、复制、Mermaid、主题或移动端回归，应保留服务端安全的代码正文输出，逐项关闭有问题的增强能力；不得退回到依赖隐式语言猜测或虚构文件名的方案。
