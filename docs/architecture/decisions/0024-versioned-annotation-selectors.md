# ADR-0024: 阅读批注采用版本化文字锚点与独立定位状态

- **状态**: Accepted
- **日期**: 2026-10-16
- **决策者**: 项目所有者（2026-10-16 确认书面设计）

## 上下文

当前 [ADR-0011](0011-rendered-text-annotation-anchors.md) 依赖浏览器正文 `textContent` 与服务端 Markdown 文本投影一致。增强代码块增加工具栏和行号、Prism 重建文本节点、Mermaid 异步增加或替换节点后，该假设不成立。服务端定位失败会设置 `deleted=true`，使仍有价值的评注退出可见列表。相关已知问题见 [TD-0005](../../engineering/technical-debt.md#td-0005增强代码块与服务端批注文本的表示不同)。

项目所有者要求长期可靠的方案，并明确要求严重错误在本地单元测试阶段被拦住；集成和浏览器测试只能补充证明环境边界。

本决策已接受，尚未实施，不描述已经实现的能力；当前行为仍以 ADR-0011 和实际源码为准。详细的协议、失效处理和测试验收以[批注锚定设计](../annotation-anchoring.md)为唯一来源。本决策实现完成后，再将 ADR-0011 标记为 Superseded。

## 决策

采用 W3C 文字引用与位置选择器的组合模型，绑定不可变文章版本；位置只是线索，引用和版本连续性才是校验依据。正文采用单一、版本化的结构化文本投影，页面与批注都使用该投影。保留原始锚点，另存当前版本的定位结果；无法确认位置时保留批注并明确显示未定位状态。

成熟实现评估固定为 Hypothesis client `a7b7400d0d706d4357ec37c2a3610b25dcca89d5`：

- 复用其纯内容块的 DOM 位置转换基础：`text-range.ts`、`trim-range.ts`，保留许可证与完整来源 SHA，通过本地适配层接入。
- 不引入完整客户端、账户、服务和侧栏。现有登录、匿名归属、PUBLIC/PRIVATE 与所有权边界保留。
- 不直接采用 `html.anchor()` 的默认模糊匹配回退。其 quote matcher 会给近似候选评分并选择最高者，不保证排除重复原文歧义。
- 复用工具仅在不含辅助节点的纯内容根内计算 UTF-16 DOM 坐标；跨块由产品的显式映射连接。不得只修改一个 walker 的过滤规则而保留另一方向的裸 `textContent` 计数。
- 持久化选择器位置采用 Unicode 码点；与工具的 UTF-16 坐标在一个适配层显式转换。文本规范化规则独立版本化。

不采用以下候选：

1. 只调整脚本顺序：不能解决修改文章后的前后端投影差异与历史数据失效。
2. 全文 diff 后覆盖原锚点或自动删除：没有保留原始依据，错误难以恢复。
3. 以最佳模糊候选作为正确结果：同文、删后重建和 Unicode 场景可能误挂。
4. 改造为协同编辑器并持久化全部编辑操作：Obsidian 整篇 Markdown 替换没有这类操作日志，本次不引入新的编辑系统。

## 后果

**正向**

- 渲染控制文字不影响批注坐标，原始引用不会随更新被篡改。
- 引用不存在或歧义时可以保留评论、解释状态，不画在未经验证的位置。
- 关键安全规则通过实际渲染链、真实 Prism、受控异步重建、版本与权限单测保护。

**负向**

- 需要数据库迁移、文章版本存储、双向文本映射和定位适配器。
- 保守判断会留下未定位批注；任意整篇替换后不能保证自动恢复同一语义位置。
- 保留最小第三方源码副本需要检查许可证、来源与升级差异；它不是受上游支持的独立 SDK。
- 过去没有保存的历史正文和原始上下文不能补造；历史记录只能按可证明的依据迁移。

## 假设

| 假设                                    | 可证伪信号（出现时重评）                       |
| --------------------------------------- | ---------------------------------------------- |
| 正文仍以 Markdown 整篇更新为主          | 出现结构化编辑操作日志或多人协作需求           |
| 各渲染组件能提供纯内容根及完成/替换通知 | 第三方组件无法隔离展示节点或无法感知内容替换   |
| 严格校验优于模糊恢复率                  | 产品明确要求自动近似关联，并愿意接受误关联风险 |
| 版本快照只用于内部定位与授权回看        | 出现公开历史版本、审计或合规保留需求           |

## 退出条件

| 信号                                     | 预设行动                                                 |
| ---------------------------------------- | -------------------------------------------------------- |
| 某渲染器不能建立可靠的文字映射           | 禁用该组件内部选词批注，保留前后正文能力，明确组件边界   |
| 单测出现错误关联、静默丢失或私有数据外泄 | 阻断提交候选和发布，先保留失败 fixture 再修复            |
| 升级上游工具改变坐标或选择器语义         | 固定旧版本，更新适配设计和测试后才能升级                 |
| 需要重排后仍无歧义识别完全相同的段落     | 单独设计由作者维护的稳定块身份，不能以序号或哈希伪造身份 |
