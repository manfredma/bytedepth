# 独立阅读 App

> 状态：Accepted，实施中。移动 API 与客户端已有实现；本文定义目标行为与系统边界，不作为 staging、APK 或手机验收的完成证据。
> 导航：[项目知识库](../README.md) · [架构概览](overview.md) · [统一语言](ubiquitous-language.md) · [移动端架构决策](decisions/0025-react-native-mobile-reader.md) · [批注锚定](annotation-anchoring.md)。

## 目标与范围

Android 独立阅读 App 首先以 APK 小范围试用，验证连续阅读、自动保存文章和本机续读；Android 验证后再交付 iOS。客户端采用 React Native；配套 Expo 与 TypeScript，使用原生组件承载列表、搜索、导航、账号和互动，专用 WebView 承载正文。WebView 读取服务端净化后的正文与固定版本阅读资源，不打开整篇网站页面。

游客可以发现文章、浏览专栏、阅读、自动保存离线副本、保存本机位置和评分。登录复用网站账号，联网查看本人批注，并按权限创建或修改划线、评注和文章评论。公开评注与文章评论联网读取。阅读历史、续读位置和公共正文副本属于当前设备，不随账号切换，也不上传。

首版不含后台管理、写文章、消息、跨设备历史同步、离线互动队列、手动下载、缓存清理入口、商店上架和远程脚本热更新。不改变现有网页历史、批注和账号规则。独立聚合阅读统计不纳入本设计；不得借用网站 tracker 自动上报。

## 页面与阅读方式

底部保留四个入口，文章阅读页使用独立导航栈。

| 入口 | 主要内容                                                  | 行为边界                                                   |
| ---- | --------------------------------------------------------- | ---------------------------------------------------------- |
| 发现 | 最近更新、分类和标签、搜索入口                            | 搜索在线进行；无网络时说明不可搜索，不伪装为全站离线搜索   |
| 专栏 | 专栏列表、专栏详情、按既有顺序排列的文章                  | 专栏内上下篇使用服务端导航模型，不按文章 ID 推断顺序       |
| 最近 | 本机阅读历史、续读位置、离线可读状态                      | 未登录也可用；被清理的文章仍有历史；撤回条目保留但不可打开 |
| 我   | 登录/注册、当前账号、联网查看本人批注、阅读偏好、版本信息 | 登录不导入或上传本机历史；无缓存清理按钮                   |

视觉延续[前端设计语言](frontend-design-language.md)：安静、以正文为主，层级主要由留白、细线与字号建立。正文不套多层卡片，元信息保持轻量；不照搬桌面页头、悬浮专栏侧栏与网页底栏。主操作触控区域至少 44×44 逻辑像素，支持系统字号、安全区、深色显示及屏幕阅读器。

阅读页顶部提供返回、文章标题和轻量状态；底部工具提供目录、评注和阅读设置，长文中不重复放全站导航。目录以底部面板展开，定位后关闭并回到正文。专栏身份与上下篇出现在文章上下文中。代码和宽表格在自身范围横向滚动，不撑宽页面；图片可预览。主题与字号只改变呈现，不改变正文投影与批注身份。首次打开不弹出登录要求。

## 客户端与服务端边界

| 部分              | 职责                                                                          | 不承担的职责                                               |
| ----------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------- |
| React Native 页面 | 导航、列表、搜索、账号、评分、互动编辑与状态反馈                              | 不重新解析 Markdown，不在组件内拼接另一套正文              |
| 本地仓储          | SQLite 保存历史、位置、缓存索引；文件保存正文包与资源；执行容量限制和原子切换 | 不同步阅读历史，不持久化私有批注与密码                     |
| 原生网络层        | 显式会话与 CSRF、版本检查、公共资源获取、在线互动                             | 不依赖 React Native 隐式 Cookie 行为，不把凭据交给 WebView |
| 阅读 WebView      | 固定阅读壳、正文布局、代码/图表、目录、选区映射与位置事件                     | 不直接登录、调用业务 API、加载网站 tracker 或任意远程脚本  |
| 现有 adapter      | `/api/mobile/v1` 输入输出、安全适配、JSON 错误                                | 不复制 app 用例或直接访问基础设施                          |
| 现有 app/domain   | 公开内容查询、版本正文、搜索、专栏、评分、评论与批注规则                      | 不感知设备文件系统、WebView 或 APK                         |

服务端不新增 Maven 模块，沿[现有依赖方向](overview.md)扩展。客户端源码放在 `apps/mobile/`，拥有自己的 package、lockfile、工具版本与依赖目录；不改根网页工程的依赖含义，也不共享 `node_modules`。Expo、React Native 及原生依赖按兼容矩阵锁定，不使用浮动 `latest`。构建与质量检查入口见[移动端开发](../engineering/mobile-development.md)；正式发布使用 canonical release-platform。

正文复用 app 层 `ArticleDocumentService` 与 `ArticleRevisionService`。它们已经提供 sanitized HTML、正文版本、投影版本、摘要和片段。普通 `PostController.detail` 同时增加 PV、发布访问事件并组装身份数据，因此不能作为下载或版本探测入口。新内容接口不产生这些页面访问副作用。

## 公共正文包与资源

正文包只包含已发布文章的公共信息：稳定文章 ID、当前 slug、标题和元信息、`contentVersion`、`projectionVersion`、文本摘要与片段、净化正文、阅读壳版本和资源 manifest。文章 ID 用于本机历史与缓存主键，slug 是可变链接信息。评分、评论、批注、用户身份、会话和 CSRF 不进入正文包。

正文版本不等于整个表示的版本：当前 `contentVersion` 只在标题或 Markdown 变化时递增，下架状态必须独立核对。资源 manifest 与正文表示具有独立摘要，阅读壳版本也必须匹配；不能把 `ArticleDocument.digest` 当作所有元信息、图片字节与渲染运行时的摘要。移动内容接口实现独立的条件请求和表示版本，不复用网页文章路由。

manifest 从净化后的正文生成，只列出实际引用的图片及固定版本阅读资源，不抓取整篇 SSR 的链接。所有正文图片均为离线完整性的必需资源，包括尚未滚入视口的懒加载图片，不能通过标为可选规避保存失败。每项具有规范化来源、资源角色、已知类型、可核验摘要或其缺失标记，以及本地映射键。不得递归抓取外链页面、任意 CSS 引用、动态 API 或私有资源。打包的固定脚本、字体与样式随客户端或明确版本正文资源交付，不按远程 HTML 的任意脚本地址执行。

当前上传图片由 `/images/**` 提供，Markdown 也可以引用站外 HTTP/HTTPS 图片；现有净化负责 HTML 与 URL，不是对下载图片字节的证明。SVG 上传存在按扩展名原样保存的路径，不能直接当作可信内联 HTML。下载层需校验响应类型、大小与实际内容，约束重定向，不向站外地址附带会话凭据；无法安全获取的资源保留说明和占位，不标完整离线。HTTP 图片不以关闭全局传输安全或放开 WebView 混合内容解决。

“离线可读”表示此副本声明的全部必需资源已经保存并校验，不保证站外资源永远最新。对于无法由服务端提供可信摘要的可变外链资源，本机摘要只能证明已保存字节的完整性；刷新时重新验证或获取，失败保留旧完整副本并说明未确认更新。单次图片成功不代表全篇资源已完成。

代码高亮和 Mermaid 使用固定本地资源；Mermaid 保存源码，图形在阅读壳内生成，失败显示源码。当前无公式渲染实现，首版不承诺自动渲染 LaTeX；若正文含未支持语法，保留可读原文，不把新增公式引擎伪称为现有能力。代码、表格、脚注、图片加载与图表变化均复用正文映射生命周期。

## 缓存状态与更新

缓存分为“副本状态”与“检查状态”，避免把网络失败误判为正文消失，或把发现新版等同于立即替换。

| 副本状态 | 含义与可见行为                                             | 转移条件                                                                     |
| -------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 无副本   | 无可恢复的正文                                             | 在线获取成功后进入暂存；离线时说明此文尚未保存                               |
| 暂存     | 新正文或资源未完成；在线可阅读已取得正文，状态显示正在保存 | 全部必需资源校验完成后发布完整副本；失败或取消则保留原完整副本               |
| 完整     | 正文、manifest 与必需资源一致，可离线打开                  | 刷新创建另一份暂存；自动容量清理后回到无副本，历史和位置保留                 |
| 不可访问 | 服务端明确确认撤回或失去访问资格                           | 清除正文与关联副本；保留不可打开的历史；以后服务端重新确认公开时才可重新获取 |

| 检查状态        | 阅读行为                                                             |
| --------------- | -------------------------------------------------------------------- |
| 未确认 / 检查中 | 每次打开发起一次版本与可见性检查；已有完整副本立即可读，不等待网络   |
| 已确认当前      | 当前可访问且表示与本机一致；展示最近确认时间                         |
| 有更新          | 只提示“有新版本，刷新”；保持正文、选区与位置，用户操作后才切换       |
| 暂未确认        | 离线、超时、限流、5xx 或认证失效；完整副本继续可读，说明暂未确认更新 |
| 确认不可访问    | 关闭当前正文和私有覆盖层，转为不可访问状态；不能继续显示旧副本       |

每次打开以及手动刷新都检查服务端当前可见性；有完整缓存时先显示副本再检查。相同文章的检查与获取合并为一个进行中的任务；离开页面取消消费者，旧回调不得影响新文章或新账号。首版检查超时为 5 秒，失败不阻断旧副本阅读；不进行后台自动重试，重试由再次打开或明确刷新触发，429 尊重 `Retry-After`。401 表示会话需要恢复，不等于文章已撤回；服务端必须返回可区分的公开内容结果，不能把登录页 HTML 当作文章或撤回证据。服务端先检查可见性再判断条件请求，304 只能表示当前仍可公开访问且表示未变化，不能跳过撤回检查。

初次打开在后台自动保存正文与全部必需资源，无手动下载按钮。发现新版不自动替换正在阅读的正文，也不悄悄把本机唯一副本切成新版。用户刷新时，先在独立暂存目录写入新正文与资源、校验摘要，再以一次本地事务发布新索引。崩溃、断网、存储不足与校验失败不得覆盖旧完整副本。启动恢复清理未提交暂存，索引不得指向不完整文件。

已确认撤回或无权阅读优先于正在进行的刷新：使在途任务失效，删除本机正文，销毁阅读 WebView 和内存互动。共享资源按引用计数回收，不误删其他文章仍需的资源。网络异常、DNS 失败、网关错误和通用 404 页面不作为撤回证明。离线期间无法得知服务器撤回，只能展示最后确认信息，不声称实时授权。

缓存有设备级字节上限，首版设为 256 MiB，由客户端单一配置声明；实际占用包括暂存和共享资源。按最近阅读时间自动淘汰最久未读完整副本，当前正在阅读的副本不淘汰；清理保留历史与位置。新旧正文原子切换期间均计入上限，不临时无限超额。若当前文章或新副本超过可用空间，阅读可以继续，但明确未完整保存，不通过删除当前唯一可读副本强行完成。无面向用户的清理入口。应用私有缓存被系统回收或卸载后，缺失文件降为无副本，不能仍显示离线可读。

## 本机历史与精确续读

历史和续读数据独立于正文文件、账号与缓存清理。每次成功打开和阅读位置变化只写本地；前后台切换、离开页面前保存最新位置，崩溃后恢复最近一次已提交位置。记录包含文章 ID、标题快照、最近阅读时间、正文/投影版本、片段 ID 与片段内码点位置、所属内容块原文及前序标题依据、视口内相对位置，并保留进度作展示信息；不只存绝对滚动像素。片段 ID 仅在同一正文版本内使用，不能跨版视为稳定身份。

同一版本在正文映射就绪后恢复目标片段，图片、字体和图表重排时保持阅读锚点，用户开始主动滚动后停止自动纠偏。目录跳转也更新本机位置。字号、旋转和设备宽度变化不应把读者送回篇首。

刷新跨版本时先保存旧位置。首版仅在所属内容块类型与完整原文在旧、新模型中均唯一且未变时，恢复该块内位置；不使用模糊搜索或同文候选排序。不能把同序号片段、相同百分比或旧 `scrollY` 称为精确位置。无法确认时，按旧位置之前的标题由近到远寻找在两版均可唯一对应的标题，定位成功后提示“正文已更新，已返回相邻章节”；没有可确认标题或旧模型已被清理时返回篇首并说明位置未恢复，不静默跳到另一处相同文字。旧位置可作为本地诊断依据保留，不提交服务端，也不与批注锚点混为一种记录。

正文资源中不加载 `reading-history-store.js`、`post-reading.js`、`#post-reading-tracker` 或站点 Service Worker；不调用 `/reading-events`、`/reading-progress`、服务端阅读历史接口。设备历史不因登录自动迁移，不出现在普通请求、错误日志或诊断上传载荷中。设备备份与迁移需明确排除这些本地缓存，不能把系统自动备份当作隐含跨设备同步。

## 联网互动与身份

公开评注、整篇评论、评分摘要与本人私有批注按需在线获取，均不混入公共正文缓存；私有数据只存当前账号内存。断网时隐藏已有私有显示，禁用互动提交并说明需联网；无离线写入队列。退出、账号切换、会话失效、App 进入后台或阅读页面销毁时清除私有覆盖层与内存，恢复前台后通过 `/me` 核验会话并重新获取，仅会话失效时要求重新登录。不同请求以账号与页面 generation 隔离，旧响应不能恢复已清空内容。公共正文、设备历史和位置保持不变。

批注严格遵守 [ADR-0024](decisions/0024-versioned-annotation-selectors.md) 与[批注锚定设计](annotation-anchoring.md)：客户端消费服务端投影、当前 placement 和原始引用，不自行执行跨版本模糊定位。新建时携带版本、摘要、精确引用、片段范围与请求 UUID。检查未完成、无法确认当前版本或已发现新版时，旧正文仍可只读，但暂停新建划线/评注并提示确认更新；不得把旧偏移提交为新版本。409 保留当前内存草稿并要求刷新/重新选择，422 解释定位失效；重试同一次创建复用 UUID，不能静默重建选区。页面与账号变化后的草稿清除，不跨账号恢复。现有 PATCH 只改评注文字与可见性，不声称所有更新已经具有正文版本冲突保护。

批注响应必须携带其 placement 所属的 `contentVersion`、`projectionVersion` 与正文 digest；三者均与当前 WebView 正文相符才绘制覆盖层。现有查询计算的是当前正文 placement，不能直接画到旧缓存正文。版本不符时仅显示批注列表及原始引用，并提示刷新正文，不尝试猜测旧版坐标。

文章评论要求登录且具备 `blog:comment:create`，当前业务规则直接生成已批准评论；列表与提交结果用原生组件展示。评论和评分不依赖文字坐标，可在联网时操作，但服务端每次提交仍须重新确认文章已发布，不能凭旧副本放行。评分允许匿名，1–5 分，每 App 安装访客身份对每篇文章一票、可以改分，与网页访客分别计票。访客身份独立于账号，清除 App 数据或重装重建身份，不以设备硬件标识替代；这不是每个真实人只能一票的保证。凭据存储在卸载后可能保留的平台上，安装标记必须阻止旧评分身份被恢复。网络不确定时先重新读取当前评分，再决定重试，避免把失败响应当作成功。

账号沿用 [Spring Session 与 CSRF](../security/authentication.md)，移动端按 [ADR-0025](decisions/0025-react-native-mobile-reader.md)使用显式会话请求头；凭据由原生网络层持有，所有写操作携带有效 CSRF，不引入 JWT。移动头与网页 Cookie 会话按路径隔离，登录/退出轮换、会话失效、限流与错误格式由配置、生命周期和路由回归测试约束，真实运行还须 staging 验证。注册仍为账号申请：`PENDING` 等待管理员审核、`ACTIVE` 可登录、`BANNED` 被拒绝；密码规则以现有服务端为准，不复制网页过时提示。

认证端点均位于 `/api/mobile/v1`：先 `GET /csrf` 建立匿名 Session 并获取 CSRF，再以表单 `POST /login` 提交用户名、密码与 CSRF，由标准 Spring Security 认证过滤器处理；成功后接收轮换后的 `X-App-Session` 并重新 `GET /csrf`。`GET /me` 返回当前账号及权限，`POST /logout` 校验 CSRF 后销毁 Session。移动请求只使用显式会话头，不回退网站 Cookie；登录失败、过期与退出均返回 JSON/HTTP 状态。首次匿名评分也先获取 CSRF；安装评分身份与匿名 Session 分别管理。

## WebView 信任边界

WebView 不持有 Session、CSRF、评分身份，不共享已登录浏览器 Cookie，不把凭据注入 HTML、URL 或 bridge。原生网络层负责在线 API，WebView 只收到完成当前展示所需的正文与临时数据；私有覆盖只在内存注入，销毁后不进入磁盘快照或浏览器持久存储。

阅读壳的代码样式在打包的 Prism 与代码组件 CSS 之后生效，正文、块级与行内代码使用现有主题变量并清除 Prism 浅色文字阴影；深色主题的语法 token 使用主题文字、弱化文字与信息色，禁用 token 的浅色背景。样式只作用于阅读文章，不能改动网站全局 Prism 配色。回归须加载真实打包 CSS 与 Prism 增强，检查浅色、深色及来回切换后的颜色、阴影、背景和阅读区外隔离，不能只验证主题变量已切换。

阅读壳加载固定本地脚本，限制网络、iframe、表单、任意导航与文件访问。文章链接先由原生解析：站内文章进入原生阅读路由，外链交系统浏览器，不在带 bridge 的 WebView 导航。图片使用已核验本地映射或无凭据的受限资源通道；不能因图片外链放开任意远程网页。

SVG 缓存保留下载原始字节与摘要，生成本地图片 URI 时再以无 I/O 的命名空间感知 XML 解析器输出 XML 1.0 被动 SVG，不能把归一化字节冒充服务端摘要所绑定的原图。兼容 draw.io 的 XML 注释、转义标签和编辑元数据；只忽略固定 SVG 1.1 外部 DTD 声明并在输出中删除，拒绝内部子集、自定义实体、脚本、事件、活动标签和外部资源引用。固定 draw.io 导出帮助链接只保留文字，不保留导航。嵌入图片仅允许经过文件魔数与尺寸检查的 PNG、JPEG、GIF、WebP，累计不超过 16,777,216 像素；SVG 根尺寸也受 8192 单边及相同像素预算约束，不允许根 CSS 覆盖宽高及其最小、最大值，解析另限制字节、深度、元素和属性数。SVG 只在 WebView 的 `img` 图片上下文解码，不交给 React Native 位图解码器，也不作为 HTML 插入；实际解码失败仍经既有 bridge 降级并丢弃完整副本。输出须再次解析为有效 SVG XML，根节点外的空白不能写成字符引用。回归必须包含代表性 draw.io 导出、畸形 XML、实体/CSS/命名空间绕过和原始摘要保留，设备验证必须覆盖真实图片加载与离线重开，不能以模拟 `Image.getSize` 成功代替。

bridge 只接受当前文章与 generation 的固定消息类型：就绪、位置、目录、选区、打开已解析链接和渲染失败。原生校验消息 schema、长度、文章 ID、版本及允许动作；拒绝任意 URL fetch、任意 JS 执行、文件路径与请求头透传。服务端仍核验所有写操作，bridge 的选区校验不能替代服务端权限与版本校验。Android/iOS 的本地资源映射和 WebView 隔离均须以正式开发构建验证，Expo Go 运行成功不代表此边界成立。

## 移动 API

以下接口位于 `/api/mobile/v1`，路径与方法按下表固定；完整 DTO 字段与错误码见[移动 API 契约](mobile-api.md)，由契约测试约束。JSON 返回明确错误码，API 不返回登录页重定向。现有网页接口保持各自协议。

| 能力与建议路径                                                                            | 请求/响应核心                                  | 复用与边界                                                                 |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------- |
| `GET /posts`、`GET /discovery`                                                            | 分页、分类/标签、公共文章摘要                  | `ListPostsQryExe` 与现有首页查询；只返回当前可见文章                       |
| `GET /search`                                                                             | 关键词、分页、结构化结果                       | `SearchPostsQryExe`；保留索引结果的发布状态与当前 slug 复核                |
| `GET /columns`、`GET /columns/{id}`                                                       | 分页专栏与有序文章导航                         | 现有专栏查询与 `SeriesNavigationQryExe`                                    |
| `GET /posts/{id}/state`                                                                   | 当前可见性、正文/表示版本、资源版本或 ETag     | 不加载 SSR，不增加 PV；失败类型与撤回结果可区分                            |
| `GET /posts/{id}/content`                                                                 | 公共正文包、投影与资源 manifest                | `ArticleRevisionService`；下载前重新核对可见性，正文包不可夹私有数据       |
| `GET /posts/{id}/ratings`、`PUT /posts/{id}/rating`                                       | 聚合分、人数、本安装评分；提交 1–5 分          | `GetPostRatingQryExe`、`RatePostCmdExe`；安装身份、CSRF与限流显式接入      |
| `GET/POST /posts/{id}/comments`                                                           | 已批准评论分页；提交结果                       | 现有评论用例与权限；不返回网页重定向                                       |
| `GET/POST /posts/{id}/annotations`、`PATCH/DELETE /posts/{id}/annotations/{annotationId}` | 可见批注、严格 anchor、所有权与冲突            | 现有 app 批注用例；私有结果禁止持久化，写操作补齐限流                      |
| `GET /csrf`                                                                               | 匿名或当前 Session 的 CSRF，必要时建立会话     | Session 标识通过 `X-App-Session` 返回，CSRF只在内存；响应禁止缓存          |
| `POST /login`                                                                             | 表单 `username/password` 与 CSRF，返回认证结果 | 标准 Spring Security 过滤器；成功轮换 Session 后重新获取 CSRF              |
| `GET /me`                                                                                 | 当前账号、权限；未登录返回 401                 | 不含阅读历史，响应禁止缓存；首版 Session 到期重新登录                      |
| `POST /logout`                                                                            | 当前会话与 CSRF，返回退出结果                  | 销毁 Session，客户端无论响应是否到达都清理本地会话与私有内存；响应禁止缓存 |
| `POST /registrations`                                                                     | 用户名、密码、待审核结果                       | `RegisterUserCmdExe`；不自动登录待审核账号                                 |

不新增移动阅读历史、续读位置或阅读事件 API。公共正文与个人互动响应分别定义缓存策略；客户端不能仅因同源或 GET 就写入缓存。`RateLimitFilter` 按“HTTP 方法 + 路径”匹配移动路由，测试覆盖 PUT/PATCH/DELETE 和编码路径；不能恢复为只匹配 POST。列表分页、资源下载上限、错误结构、客户端兼容版本和条件请求语义由契约测试约束；API 返回 schema 版本不得由数据库实体序列化意外决定。

## 发布与平台前置门禁

Android 先交付签名 APK 小范围试用。正式产物必须能够核对源码完整 SHA、客户端版本、包名、签名证书指纹、APK digest、关联服务端 API 版本与验证 evidence。安装升级保留本机数据；降级或不兼容数据库迁移不能默认清空历史。

当前仓库与[发布说明](../../deploy/README.md)只证明 JVM JAR、宿主机 systemd 和网页验证链。release-platform 是否支持 React Native 构建、Android SDK/NDK 版本、APK 签名密钥隔离、不可变制品与下载分发尚未知。相关能力及测试 runner 未被平台正式验证前，不宣称可以交付正式 APK，不借用 JAR 发布链，也不从工作区直接发布。发布仍由 canonical release-platform 与 Host Agent 编排。

本机模拟器和临时构建探针仅证明开发工具可用，不能当作 staging 验收或已签名试用包证据。staging 是唯一集成、端到端与验收环境；客户端测试连接 staging API，发布验收绑定同一服务端候选及客户端制品，遵守[项目发布边界](../engineering/release-platform-only.md)。

## 验收矩阵

以下是实施必须满足的行为，不代表已有测试通过。状态机、存储恢复与 bridge 使用离线行为测试；实际 WebView、Session、安全区、键盘、图片与图表通过 Android 真机/模拟器连接 staging 验证，不能由 DOM 模拟器替代。

| 场景                       | 必须可观察的结果                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| 游客首次阅读               | 无登录阻断；正文可读，自动保存完成前不显示离线可读                                                 |
| 完整资源与异常图片         | 所有必需资源校验后才标完整；HTTP、站外失败、错误类型与过大资源不伪装成功                           |
| 断网/超时/429/5xx          | 已有完整副本继续可读并显示未确认；无副本说明原因；无无限重试                                       |
| 检测新版                   | 保持当前正文与位置；只有用户刷新才切换                                                             |
| 刷新失败/进程中断/存储不足 | 旧完整副本仍能打开；启动后不读取半写正文或悬空索引                                                 |
| 联网确认撤回               | 当前显示关闭、正文清除、在途下载不复活，历史保留不可打开条目                                       |
| 离线后撤回                 | 离线只展示最后确认信息；再次联网收到明确撤回立即执行清除                                           |
| 容量淘汰/文件被系统移除    | 最久未读副本先淘汰，当前阅读副本保留；历史与位置不丢；缺失资源降级状态                             |
| 同版精确续读               | 重启、旋转、字号、图片/字体/图表重排后仍恢复同一内容位置，不在用户滚动后反复抢位置                 |
| 跨版续读无法确认           | 明确提示位置未恢复；不以百分比或重复文字猜测精确位置                                               |
| 本机数据隐私               | 游客/登录/换号均不上传历史或位置；抓取请求和日志核对无 tracker、reading-events、reading-progress   |
| 账号与私有数据             | 注册待审核不可登录；会话轮换/过期有明确结果；后台/退出/离线/换号后无旧私有显示、文件与过期回调     |
| 匿名评分                   | 首次无需登录，同安装同文章改分不增加人数；与 Web 身份分离，清除数据/重装重建身份                   |
| 评论与批注权限             | 无权限写入被服务端拒绝；私有记录不泄露；离线没有待发送队列                                         |
| 旧文批注/重试              | 缓存版本不同禁用新建；409/422保留同页面内存草稿；同 UUID 重试无重复，销毁页面后旧响应不写回        |
| 内容与锚点                 | 中文、emoji、表格、代码、脚注、Prism、Mermaid成功/失败均遵 ADR-0024；不在图形文字绘制伪定位        |
| WebView/bridge             | 外链不能接管 bridge；恶意消息/图片/SVG/导航不能读取凭据、任意文件或执行原生请求；WebView无业务凭据 |
| APK 安装与升级             | 同签名升级保留缓存索引与历史；制品 digest、SHA与证书可复核，正式平台 evidence 完整                 |

## iOS 演进

iOS 复用 React Native 页面、领域交互、API、本地 schema 与缓存状态机；平台适配集中在 WebView 本地资源、网络会话存储、安装身份、安全存储、后台生命周期和安全区。不能把 Android WebView 行为外推为 WKWebView 已验证，也不能依赖卸载后一定删除的系统安全存储维持“每次安装”的边界。

Android 验证后，以同一验收矩阵在 iOS 补充 WKWebView、系统字号、VoiceOver、键盘遮挡、前后台与资源恢复测试，再确认 iOS 签名和分发能力。首版不提前引入独立 iOS 业务服务或另一套正文渲染。
