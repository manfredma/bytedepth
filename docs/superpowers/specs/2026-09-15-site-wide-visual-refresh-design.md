# bytedepth 全站视觉与页面风格改版设计

## 目标

在不迁移 React/Vue、不改变现有服务端渲染边界的前提下，建立统一的 bytedepth 视觉系统，并重做首页内容编排。公开站点采用编辑型工程内容站气质；后台复用同一套品牌令牌，但保持高密度工作台体验。

## 技术决策

- 保留 Spring Boot + Thymeleaf 服务端渲染。
- 不新增前端框架或构建工具。
- 继续使用原生 JavaScript 完成主题切换、导航和轻量交互。
- 保留现有 logo.svg 与 favicon.svg；logo 的环、节点、渐变元素作为首页视觉语言的来源。
- 将首页内联样式迁移到独立、命名空间化的 CSS 文件。

## 视觉系统

- 深靛蓝品牌底色、紫色主交互色、珊瑚色状态强调色。
- 公开内容使用暖白纸张背景，文章标题使用衬线字体，界面和元数据分别使用无衬线与等宽字体。
- 以 4/8/12/16/24/32 间距梯度、三档圆角和克制阴影建立令牌。
- 共享主题令牌由 theme.css 定义，浅色、深色及现有主题通过令牌切换。

## 页面结构

### 共享导航

继续由 fragments/nav.html 提供。公开页和后台页共享品牌、搜索、主题、权限入口、关于菜单和 staging 提示；桌面端单行，小屏幕品牌/操作与横向导航分层。导航样式全部收敛在 nav.css。

### 首页

首页分为视觉封面、文章流和探索栏。封面使用稳定站点宣言与 logo 衍生的原创抽象图形，不再使用随机名言轮播。主区域保留 discovery/latest/hot 和分页；右栏展示分类、热门文章与项目状态。分类不再作为顶端主区块。

首页主推文章优先读取已发布且 featured=true 的文章；没有主推文章时降级为最新文章，不新增后台编辑能力。

### 其他公开页

文章列表、详情、专栏、项目、搜索、关于、网络地图和版本页复用 page-shell/page-header 视觉骨架，页面专项内容保持原有数据和交互语义。文章详情以正文阅读为首要层级。

### 后台

后台使用同一品牌令牌与导航，但采用紧凑的 page-shell、操作区、筛选区和表格/表单布局；不复用首页装饰性视觉封面。

## CSS 与组件边界

新增或整理 site-shell.css、page-header.css、post-list.css、topic-explorer.css、project-panel.css、admin-components.css 等资源。每个组件使用独立命名空间；模板仅保留结构和 Thymeleaf 绑定，禁止新增全局裸选择器和页面内联样式。已有分页、过滤栏、确认弹窗接口不变，仅统一视觉令牌。

## 验证

- 本机执行 `npm ci --ignore-scripts --no-audit --no-fund` 后运行 `bash scripts/run-local-quality.sh`。
- 补充首页主推文章有/无、discovery feed、排序分页和导航渲染测试。
- 候选分支部署 staging，验证公开页与后台在桌面、平板、320/375px、小数据/空数据、浅色/深色主题及登录/未登录状态。
- staging 集成和 E2E 必须全绿且无未处理 WARNING，生成与候选完整 SHA 绑定的 evidence；项目所有者验收后才合并 main。
