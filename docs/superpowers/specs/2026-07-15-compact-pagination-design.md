# 紧凑分页组件设计

## 目标

将公共分页改为阅读优先的紧凑样式，降低页面底部的视觉密度，同时保持现有页码窗口、上一页/下一页和指定页跳转能力。

## 设计

- 组件根节点统一使用 `bd-pagination-*` 命名空间，并在组件内部声明字体、尺寸、颜色、间距和盒模型；不再依赖页面级 `.pagination` 或 `.page-btn` 样式。
- 主导航保持单行：紧凑的前后页按钮、页码窗口和省略号。当前页为唯一强调元素；普通页码只在悬停或键盘聚焦时显示浅色背景。
- 总数与进度信息移到导航下方，以低对比度小字显示。
- 指定页跳转从常驻表单收纳为一个带 `details` 的“跳至”入口；展开后显示页码输入框与确认按钮。移动端可换行且保持不溢出。
- 保持 fragment 参数、URL 拼接、输入范围校验和回车跳转不变，避免影响首页、文章、搜索、专栏和后台的调用方。

## 验收标准

- 模板不再输出 `.pagination`、`.page-btn`、`.page-jump` 等无命名空间的分页样式选择器。
- 当前页、禁用页、页码链接和跳页控件均有可辨识状态与键盘焦点样式。
- 所有调用方无须变更；现有 URL 和页码渲染算法保持不变。
- 新增模板结构回归测试，并通过全量 Maven 测试。
