# 专栏文章导航重设计

## 状态

已确认，进入实现与 staging 验收。

## 背景

文章详情页目前按全站发布时间计算“上一篇/下一篇”，专栏文章会跳出当前专栏；专栏目录只通过左侧固定抽屉提供，文章开头无法立即识别专栏位置，且底部导航卡片在桌面端视觉重量过大。

## 目标

1. 专栏文章的连续阅读顺序严格使用 `series_order ASC`，不跨专栏。
2. 文章开头显式展示专栏身份、当前篇号/总篇数和阅读进度。
3. 文章开头提供可展开的完整专栏文章选择器，支持跳转到任意已发布文章。
4. 桌面端上下篇导航改为紧凑导航条；移动端保持足够的触控区域。
5. 专栏边界提供语义明确的动作：第一篇返回专栏，最后一篇进入专栏目录。
6. 非专栏文章保留全站上一篇/下一篇，并用“全站”文案区分语义。

## 非目标

- 不改变后台专栏编排、`series_order` 编辑和专栏列表页。
- 不新增文章历史或新的持久化字段。
- 不让草稿出现在公开专栏选择器中。

## 交互设计

### 文章开头专栏上下文

仅当当前文章属于专栏时，在标题前渲染专栏上下文块：可点击专栏名称、`第 N 篇 · 共 M 篇`、进度条，以及默认收起的“查看本专栏全部文章”选择器。选择器展开后按专栏序号列出所有已发布文章，当前文章高亮，列表可独立滚动，点击标题直接跳转到 slug URL。

### 上下篇导航

- 专栏中间文章：显示同专栏相邻文章的篇号、标题和方向。
- 专栏第一篇：左侧动作显示“返回《专栏名》”，链接专栏详情页；右侧为第二篇（若存在）。
- 专栏最后一篇：左侧为倒数第二篇（若存在）；右侧动作显示“查看专栏目录”，链接专栏详情页。
- 单篇专栏：左右都显示返回专栏/查看专栏目录动作，不渲染跨专栏文章。
- 非专栏文章：显示“全站上一篇/下一篇”，继续使用原全站发布时间顺序。

桌面端导航条高度约 62px，使用细分隔线、短篇号和单行标题，不使用大块卡片背景；移动端高度约 76px，允许标题换行并保留触控间距。

## 数据与组件边界

新增专栏导航查询模型，由应用层根据已发布专栏文章列表计算当前索引、总数、进度、上一篇和下一篇，保证目录与相邻导航使用同一排序快照。排序必须稳定为 `series_order ASC, id ASC`。公开查询只消费 `PUBLISHED` 文章；当前草稿若被作者或管理员预览，不展示公开专栏导航项。

详情页控制器只负责组装模型，不在模板中推导顺序。模板拆分专栏上下文块、文章选择器和上下篇导航的职责；删除现有左侧固定专栏抽屉及其专用脚本，避免同一能力重复呈现。

## 可访问性与响应式

- 选择器使用按钮/列表语义，提供 `aria-expanded`、当前项标记和键盘可达链接。
- 所有文章标题链接使用 slug URL；当前项不重复跳转，可保留链接但以 `aria-current="page"` 标识。
- 移动端选择器列表限制高度并独立滚动，正文不被横向溢出影响。
- 主题色沿用现有专栏深蓝、强调金色和页面边框变量，不把环境样式放入专栏组件以外的页面主题。

## 验收标准

- 专栏中间、首篇、末篇、单篇四种情况均只在专栏内导航，且链接目标正确。
- 选择器可列出专栏所有已发布文章并跳转任意一篇，当前文章高亮。
- 非专栏文章仍可使用全站导航，文案标记“全站”。
- 桌面端导航条明显小于现有卡片，移动端可触控且标题不溢出。
- 单元测试覆盖导航计算的所有业务分支；模板/控制器测试覆盖模型和边界文案；staging E2E 覆盖选择器展开、任意跳转、首末篇和桌面/移动布局。
