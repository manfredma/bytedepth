## 设计决策

### 核心概念

- **图形**：双层旋转光环 + 中心圆 + `bd` 字母
- **`bd`**：bytedepth 首字母缩写，等宽字体（SF Mono / Fira Code / Courier New），字重 700
- **四个彩点**：上下左右各一个，顺时针绿→青→紫→紫，依次呼吸闪烁，像指南针
- **隐喻**："深入探索"的轨道感，双环反向旋转形成时钟张力

### 动效参数

| 元素 | 方向 | 速度 | 说明 |
|------|------|------|------|
| 外圈虚线环（r=48） | 顺时针 | 20s/圈 | 沉稳，时钟秒针感 |
| 内圈虚线环（r=38） | 逆时针 | 12s/圈 | 相对较快，与外圈形成张力 |
| `bd` 文字 | — | 3s 呼吸 | 绿→青发光循环 |
| 四个彩点 | — | 1.8s 呼吸，间隔 0.45s | 依次错开，流动感 |

### 配色

| 用途 | 颜色 |
|------|------|
| 渐变起点（绿） | `#34d399` |
| 渐变中点（青） | `#38bdf8` |
| 渐变终点（紫） | `#818cf8` |
| 内圆背景 | `#062a22` |
| 内圆描边 | `#34d399` 40% opacity |
| 第四彩点 | `#a78bfa` |

浅色背景适配色：绿 `#059669`、青 `#0284c7`、紫 `#7c3aed`，内圆背景 `#ecfdf5`。

### 尺寸退化规则

| 尺寸 | 呈现方式 |
|------|---------|
| 64px、48px | 完整：双环 + 彩点 + `bd` |
| 32px | 简化：外圈 + 内圆 + `bd`，去掉内圈和彩点 |
| 16px（favicon） | 最简：纯深色圆 + `bd`，无环无点 |

---

## 交付物

- `favicon.svg` — 静态版本，用于 `<link rel="icon">`
- `favicon.ico` — 16×16 + 32×32 多尺寸 ICO（兼容旧浏览器）
- `logo.svg` — 带动效的完整版本（图标 + 文字 logo 组合）
- HTML `<head>` 引用片段
