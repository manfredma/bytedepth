# Dynamic Editorial Home Design

## Goal

重做首页为真实数据驱动的技术内容入口，同时统一非后台公共页头与配色；文章详情及其他非首页页面只允许修改页头和主题样式。

## Confirmed product rules

- 首页定位为技术内容出版物，知识网络与项目作为辅助入口。
- 首页顺序：站点定位与真实统计 → 本期主推 → 最近更新 → 推荐阅读 → 分类/项目 → 网络地图。
- 后台可推荐多篇文章；首页取最新推荐文章作为主推，其余最多 4 篇进入推荐阅读。
- 推荐排序使用独立的 `featured_at`；推荐取消时清空。
- 推荐理由由后台填写，使用 `featured_reason`；没有理由时不显示理由块。
- 热门文章继续由已有阅读量排序；发现/最新/热门语义不变。
- 首页统计只使用已有真实口径：已发布文章数、顶级分类数、项目数。
- 没有推荐文章、项目或热门数据时显示明确空状态或隐藏模块，不使用假数据。
- 首页 slogan 放在右侧品牌 logo 下方，以小字号展示；保留轮播能力。
- 所有非后台页面共用 `fragments/nav.html` 的页头和主题变量。
- 文章详情、专栏、搜索、项目、关于、网络地图、个人页不修改内容结构、Markdown/代码渲染、目录、评论、评分、阅读进度、专栏上下篇或交互脚本。
- 不执行仓库内 staging/production 发布；由 release-platform 处理候选与验收。

## Data contract

`Post`/`PostDO` 增加 `featuredAt` 与 `featuredReason`；`PostDTO` 暴露两字段。推荐查询只返回 `status = PUBLISHED AND featured = true`，按 `featured_at DESC, published_at DESC, id DESC` 排序。`HomeController` 将查询结果拆为 `featuredPost`（第一条）和 `recommendedPosts`（最多四条），没有结果时均为空。

## Visual contract

- 主色：墨色、暖纸白、铜橙，沿用主题切换变量而不在页面硬编码第二套主题。
- 首页使用编辑部式内容层级，不再用厚重卡片堆叠。
- 公共页头在所有非后台页面一致，登录、注册、搜索、主题、RSS、关于和版本入口不丢失。
- 公共页头 slogan 小号显示在品牌文字下方；首页右侧品牌标记下方同步展示同一 slogan。

## Acceptance criteria

- 首页主推文章标题、摘要、分类、推荐理由、发布时间和进入阅读链接全部来自后台数据。
- 后台取消所有推荐后，首页不出现静态主推占位文案。
- 多篇推荐按 `featured_at` 取第一条为主推，其余最多四条进入推荐阅读。
- 首页发现/最新/热门、分类、项目和分页现有入口保持可用。
- 非首页模板 diff 只允许共享页头 fragment、主题变量及其组件样式；详情页内容模板和脚本零改动。
- 相关单元/模板测试覆盖推荐存在、推荐为空、多篇排序、推荐理由为空和旧入口保留。
